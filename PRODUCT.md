# Wonop Playback

Wonop Playback is a Spotify-style listening workspace for a person's connected
account. It supports catalog search, playlist/album/artist detail, saved
library and queue views where Spotify grants allow them, plus a persistent
player for supported playback controls.

The primary user is already signed into Spotify and wants a complete listening
workspace inside Wonop. Success means navigation and search feel native to a
desktop music player, track identity and transport remain available while
browsing, and consent, empty, and missing-device states are useful rather than
diagnostic clutter.

Spotify remains the source of playback and catalog browsing. The package never
claims that general Mac audio hardware, microphones, speakers, or calls are
Spotify Connect devices.
